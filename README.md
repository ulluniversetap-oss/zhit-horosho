# ЖК «Жить хорошо» — лендинг

Статический прототип: один `index.html` + ассеты рядом. Без сборки, без зависимостей — открывается напрямую или локальным сервером.

## Структура

```
zhit-horosho/
├── index.html
├── assets/
│   ├── images/     фотографии, иконки офферов, мокап презентации
│   ├── icons/      pdf-badge.svg (кольцо «Обновлён 14.09.26»)
│   └── fonts/      RoadRadio-Bold.ttf (самохостится; Onest — из Google Fonts)
└── README.md
```

## Запуск

Любой статический сервер подойдёт, например:

```bash
npx serve .
# или
python3 -m http.server 8080
```

Открывать `index.html` напрямую двойным кликом тоже можно — все пути относительные.

## ⚠️ Готово

- `assets/images/hero-bg.jpg` — постер для hero-видео, кадр из `assets/videos/hero-bg.mp4`
  (вытащен через `ffmpeg -ss 0.5 -frames:v 1 -vf scale=1920:-1`).
- `assets/images/family-house.jpg` — фото дома уже на месте.

## Незаполненные данные

- Блок «Всё нужное — в пешей доступности»: тайминги пешком до объектов — везде стоит «—».
- Координаты ЖК на карте (`.walk-map-frame` iframe) — сейчас ориентир по Советскому району,
  не точка дома. Адрес Новосибирская, 37 ещё не зарегистрирован.
- Блок «Горячая вода — всегда» скрыт (`display: none` на `.heat`) — разметка и стили в файле сохранены.

## Шрифты

- **RoadRadio** — заголовки, self-hosted (`assets/fonts/RoadRadio-Bold.ttf`), только вес 700.
- **Onest** — весь остальной текст, подключается из Google Fonts (`<link>` в `<head>`), требует интернет при разработке.
